# 板级原理图记录

来源：项目根目录 `bd6s40a_mini_g431-20mR.jpg`，用户确认是本项目板子原理图。
整理日期：2026-10-24。后续修改硬件相关固件时，先查本记录并回看原图。
本记录描述图纸，不代表实物已测量验证，也不代表当前 CubeMX 配置正确。

## 主电路

- 板名：火柴 FOC / Match FOC，图中参数对照列名为 `huochaiFOC`。
- 主控：STM32G431，图中器件标注 `STM32G431_48P`。
- 输入网络名：`DC_IN_24V`；图中标注“最大支持48V”。这是图纸标注，不是实物耐压验证。
- 三相输出：OUT1、OUT2、OUT3。
- 三相桥驱动：U2，EG2124A；桥臂由六颗标注为 5511D 的 MOS 管构成。
- 驱动电源：VCC_10V；逻辑电源：VCC_5V、VCC_3V3。
- 高侧自举：DSK36 二极管，220 nF 自举电容。

## PWM 接线

| MCU 引脚 | 定时器信号 | 驱动器输入 |
| --- | --- | --- |
| PA8 | TIM1_CH1 | H3 |
| PA9 | TIM1_CH2 | H2 |
| PA10 | TIM1_CH3 | H1 |
| PC13 | TIM1_CH1N | L3 |
| PA12 | TIM1_CH2N | L2 |
| PB15 | TIM1_CH3N | L1 |

驱动器输出 HO1/LO1 对应 OUT1，HO2/LO2 对应 OUT2，HO3/LO3 对应 OUT3。
因此按图纸连线，TIM1 通道 1/2/3 分别对应 OUT3/OUT2/OUT1。
后续电流与 PWM 的相序映射必须核对，不能直接默认通道 1 就是 OUT1。

## 电流采样

- 三路低侧分流：R17、R18、R19，均为 **20 mΩ、±1%、2512**。
- 电流网络：VShunt_1、VShunt_2、VShunt_3，经板上调理电路接 MCU 运放。
- 图中 huochaiFOC 参数列：

| 参数 | 数值 |
| --- | --- |
| R_pullup | 22 kΩ |
| R_pulldown | 976 Ω |
| R_in | 10 kΩ |
| Gain_offset | 0.0855 |
| Offset | 2.051 V |
| GAIN_op | 16 |
| R_sample | 20 mΩ |

- 图中说明：该板电流采样放大倍数为 B-G431B-ESC 的 3/20；采样电阻为其 20/3，整体采样电压倍率基本一致。
- 不能只用 `ADC电压 / (0.02 × 16)` 换算电流；需考虑板上调理比例、零偏、极性及实测校准。
- 表格偏置是图纸值，运行时的零电流 ADC 偏置应实际测量。
- 每相的运放正负输入、内部 ADC 路由需要在原图及器件资料中逐一核对，不以现有生成代码作为接线证据。

## 其他采样与控制

- 母线电压：VBUS_ADC，接 PA0。
- 图纸注明：输入大于 24 V 时，PB10 需置高，`VBUS_PARTITIONING_FACTOR` 调整为 `0.050556`。
- PB10 对应图中 `48V_EN` 网络，控制 Q48 分压支路。
- 温度：Temp_ADC，NTC 标注 NTCG163JF103FT1，配 4.7 kΩ 下拉；网络接 PB14。
- 反电动势：BEMF1、BEMF2、BEMF3，各相经 33 kΩ 接入，公共参考由 22 kΩ 网络构成；图中注明无感程序 `BEMF_ON_SENSING_DIVIDER` 需改为 16。
- 速度输入：SpeedBT_ADC；图中同时有 RW1 电位器和测试点。

## 通信、编码器接口与调试

- H1/A、H2/B、H3/Z 分别接 PB6、PB7、PB8；可作为 A/B/Z 编码器信号或霍尔信号接口，不能仅凭接口名认定电机传感器类型。
- A/B/Z 接口带上拉、对地电容及 100 Ω 串联电阻。
- USART2 网络名 TXD2、RXD2，有独立测试点。
- CAN 收发器：U8，SIT1042T/3；CANH/CANL 间 120 Ω 终端电阻。
- 图中明确注明：使用 CAN 时，**PC11 必须拉低**（CAN_SHD）。
- SWD：PA13/SWDIO、PA14/SWCLK；有对应测试点。
- STATUS LED：PC6。
- BUTTON：上拉，按键接地。

## 使用本记录时的边界

- 原理图不能提供电机极对数、编码器每圈实际计数、编码器方向、电角度零位及 PID 参数，这些需要电机资料或实测。
- 不把驱动器 H1/H2/H3 与 TIM1 通道编号视为同序。
- 不把图纸“最大支持48V”作为可立即给实物上 48 V 的验证结论。
- 如原图局部文字不清，先核对原图；不要补写未经确认的器件参数或引脚。

## 已确认的开机标定需求与采样配置核对

- 用户确认：每次开机进行一次转子对齐，强制控制角度为 0，目标 Id=1 A、Iq=0；电角度零偏只保存在 RAM，不写 Flash。
- 当前阶段先核对电流采样配置；尚未接通对齐电流控制，不得把这些需求当作功能已实现。
- 从原图放大核对：OPAMP1 正输入 PA1、负侧参考 PA3；OPAMP2 正输入 PA7、负侧参考 PA5；OPAMP3 正输入 PB0、负侧参考 PB2。
- 负侧参考网络 Curr_fd1/2/3_OPAmp- 分别接 VShunt_1/2/3-，为分流电阻低端参考；不是运放输出到负输入的外接滤波电容网络。
- 按 HAL 对 PGA 连接方式的定义，使用该外部负侧参考时，应选择 `OPAMP_PGA_CONNECT_INVERTINGINPUT_IO0_BIAS`，三路均选择 `OPAMP_PGA_GAIN_16_OR_MINUS_15`；当前 `...IO0` 是 VINM0 外接反馈滤波连接，不能仅调整 Gain 而忽略连接方式。
- 核对时生成代码为 OPAMP1=16 倍、OPAMP2/3=2 倍，三路 PgaConnect 都为 `...IO0`，需用户在 CubeMX 同步调整。
- 正输入网络含 22 kΩ 上拉、976 Ω 下拉、10 kΩ 分流输入电阻，其分流电压传递比例为 `(22k || 976 || 10k)/10k ≈ 0.08546682`。
- 在参考地近似为 0 V、供电 3.3 V、PGA=16 时，理论零电流输出约 2.051204 V，总电流灵敏度约 `0.020 × 0.08546682 × 16 = 0.02734938 V/A`；12 位、3.3 V ADC 约 33.94 码/A。
- 上述为原理图标称元件推导值；实际换算须使用零电流偏置校准，并验证电流符号、相序和比例。
